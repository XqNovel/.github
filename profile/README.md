## OurCraftMC

这里是OurCraft的Github界面！官方网站：ourcraft.cn

## 什么是OurCraft？

OurCraft是一个Minecraft正版公益的服务器：我们的定位不只是一个 Minecraft 服务器，而是一个朋友圈，在这里，可以感受到我们那浓浓的友

情。在OurCraft 里，我们如同家人朋友一般，在游戏里建筑房子、探索世界、看日出日落。这，就是 OurCraft。

## OurCraft的特点

- 原版体验的MC服务器：使用最新Minecraft游戏版本。没有添加任何TP、HOME等插件及MOD，以保证纯原版的游戏体验。

- 小镇制度：基于小镇管理。每位玩家可以加入自己喜欢的小镇，和其他玩家一起玩乐。也可以选择自己建立小镇，成为管理一方的镇长。

- 自由开放的社区：启用正版验证。我们给予玩家最大的自由，在除影响他人的行为外，我们不对任何行为做出限制。
